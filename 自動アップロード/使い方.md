# 自動アップロード（Windows・旅行プランナー）

作業の場（Claude）がこのフォルダーに更新を置くと、1分以内に GitHub（asatoh412-spec/tabi-planner）へ送られ、Cloudflare Pages が自動で組み立てて https://tabi-planner.pages.dev に公開する。

- 最初に一度だけ、PowerShell で次を実行する（Git for Windows が必要）
  powershell -ExecutionPolicy Bypass -File "%USERPROFILE%\source\repos\tabi-planner\自動アップロード\install.ps1" https://github.com/asatoh412-spec/tabi-planner.git
- 結果は auto-push.log に残る
- タスクスケジューラーの「AutoPush-xxxxxxxx」が1分ごとに確認する
